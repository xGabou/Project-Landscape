# Task 0 access migration inventory

All 65 original `accessible` entries have a native Forge `public` AT equivalent. This inventory was checked against ForgeGradle's generated official-to-SRG mapping and the actual AT, with **65/65 exact matches**. The AT also matches the repaired Loom Forge artifact's access set.

No access restriction was intentionally tightened. Existing accesses were retained, including compatibility-only GUI/vanilla members; unused-access pruning is outside Task 0. Surface/noise members serve density/surface generation, world-selection/data members serve preset export, and remaining members serve existing structures, caches, and client controls. Compilation, preset export and full chunk generation exercise these groups; this is not a claim that every exposed member was executed individually.

All replacements are in `src/main/resources/META-INF/accesstransformer.cfg`. No access widener is distributed. Existing `ScreenInvoker` remains unchanged; no new production accessors were needed.
